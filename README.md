# Resolve Effects Cache

A collection of DaVinci Resolve effects, macros and Fusion templates made for my PMVs. They are free to download and use in your own projects.

## Effects

| Effect | What it does | Docs |
|---|---|---|
| **RGB CRT Sim** | A CRT monitor look built from a red, green and blue phosphor mask, with scanlines, chromatic aberration, vignetting, curved lens distortion, glow and reflections. | [Manual](RGB-CRT-Sim/README.md) |

More will be added as I make them.

## Download

Download the latest effects from the [Releases page](../../releases). Each release includes the `.drfx` files. Please use the Releases page rather than the files in the repo folders, as the releases are the official packaged versions.

## Installation

1. Download the `.drfx` file you want from the Releases page.
2. Double-click it and follow the DaVinci Resolve install prompt.
3. Restart Resolve.
4. On the Edit page, find the effect in the Effects library and drag it onto a clip or an adjustment clip.
